## 背景

使用多个 Agent 工具时，任务状态分散在不同窗口里。这个桌面宠物的目标是把“Agent 正在做什么”变成一个可见、低打扰的状态指示：思考、执行、等待确认和完成，对应不同的动画与提示。

## 目标

- 常驻桌面的透明窗口，不遮挡正常操作。
- 根据 Claude Code / Codex / Trae 的 hook 事件切换状态。
- 支持游戏、音乐等使用模式的广播。
- 像素级点击穿透：角色可见区域可交互，其余区域不拦截鼠标。
- 提供可安装的 hooks 配置脚本，降低接入成本。

## 实现

桌面层使用 Tauri 2，窗口透明、无边框、置顶。前端使用原生 JavaScript 渲染精灵动画，避免为一个小窗口引入完整框架。

资源处理使用两个脚本：

- `slice-sheet.js` / `slice-extra.js` 把表情贴纸与动作精灵表切成独立帧。
- `slice-game.js` / `slice-music.js` 处理游戏与音乐状态的特殊动画。

Agent 接入通过本地 hooks 完成。`install-claude-hooks.js` 负责写入和移除 Claude Code 的钩子配置；窗口收到事件后，通过一个轻量状态机切换动画与气泡文案。

## 关键问题

### 多个 Agent 同时工作

同一时间可能有两个 Agent 在运行。状态不能简单地“后到覆盖先到”，而是按照优先级聚合成一个当前状态：等待人工确认优先于执行中，执行中优先于空闲。这样用户不会因为另一个 Agent 的空闲事件而丢失需要处理的提醒。

### 像素级穿透

Tauri 的窗口级穿透只能做到整窗，无法满足“角色可点、背景穿透”的需求。最终通过读取当前帧的透明像素来判断鼠标位置，并动态切换窗口的鼠标事件穿透状态。动画帧变化时需要重新计算，避免点击区域和视觉区域错位。

### 资源与打包

精灵表来自不同来源，尺寸和帧率并不统一。切片脚本会输出统一的元数据，前端按元数据播放，避免把帧数写死在代码里。打包与首个正式发布仍在处理中。

## 当前状态

核心的状态机、hooks 安装脚本、动画切换和窗口穿透已经可以运行。还需要完成：

- 跨平台打包与自动更新。
- 首次启动的引导与 hooks 检测。
- 更多 Agent 的事件适配。
- 发布用的资源体积优化。

## 复盘

这个项目最大的难点不是桌面技术，而是**状态建模**：多个 Agent、多种使用模式和人工交互会同时发生。先把状态和优先级定义清楚，再写动画，返工明显更少。

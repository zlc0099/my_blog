> 来源：本地技能 `~/.claude/skills/ui-ux-pro-max`，也就是我平时说的 `ui-max`。已安装；日志中没有记录到直接 `Skill` 调用，可能通过其他 Agent、插件或手动引用使用。

## 它是什么

面向 Web / 移动端 / 桌面端的 UI/UX 设计智能库，用来查风格、配色、字体、交互和实现方案。

## 本地可检索的内容

- 79 种可检索风格（50 种 active）
- 192 套产品配色与推理配置
- 74 组字体搭配
- 119 条 UX 规范
- 105 个图标、17 个 GSAP 预设、25 种图表
- 22 个技术栈的 UI 实现资料

## 我会用它做什么

做页面之前先查风格和配色方向；已有页面卡在布局、字体或交互细节时，用它找参照和检查项。它更像设计资料库，不直接替代具体实现。

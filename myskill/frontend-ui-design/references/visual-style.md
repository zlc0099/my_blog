# 视觉风格规范：配色 · 字体 · 间距 · 圆角 · 阴影

## 1. 配色方案

### 1.1 色彩角色模型

每个界面只允许出现 6 种色彩角色，全部定义在 Token 中：

| 角色 | Token | 用途 | 占比 |
| --- | --- | --- | --- |
| Primary | `--color-primary` | 主按钮、关键操作、选中态、品牌强调 | ~10% |
| Secondary | `--color-secondary` | 次要操作、辅助强调 | ~5% |
| Success / Warning / Danger | `--color-success` 等 | 状态反馈，语义固定不可挪用 | 少量 |
| Neutral（灰阶 8–10 档） | `--color-gray-50…950` | 文字、背景、边框、分割 | ~85% |

**60-30-10 法则**：中性色约 60%（背景/表面）、次级色约 30%（文字/边框）、品牌色约 10%（强调）。

### 1.2 预设配色方案（无品牌色时按风格选用）

| 风格 | Primary（示例） | 气质 | 适用 |
| --- | --- | --- | --- |
| 专业蓝 | `#2563EB` | 可信、稳重 | 企业工具、SaaS、金融 |
| 靛紫 | `#6366F1` | 现代、科技 | 开发者产品、AI 产品 |
| 翠绿 | `#10B981` | 健康、成长 | 健身、理财正向场景 |
| 琥珀橙 | `#F59E0B` | 活力、温暖 | 消费、社交、内容社区 |
| 玫红 | `#E11D48` | 时尚、大胆 | 品牌/营销页（慎用于工具类） |

### 1.3 派生规则

- Primary 需派生 3 个变体：`primary-hover`（加深 ~12% 亮度）、`primary-active`（再加深）、`primary-light`（与白混合 ~90% 用于浅色底）。
- 灰阶按明度阶梯预定义 50/100/200/300/400/500/600/700/800/900，用固定明度差保证和谐；带一点点蓝相（如 `#0F172A` 而非纯黑）会更高级。
- 禁止在 Token 之外临时取色；需要新的颜色时先更新 Token 再引用。

### 1.4 深色模式

- 不用纯黑 `#000` 做背景，用 `#0F172A` / `#111827` 级别的深灰。
- 深色下文字用高亮度灰（`#E2E8F0`），避免纯白，减少刺眼。
- 阴影在深色模式下几乎不可见：改用**表面色差**（surface 比 background 亮一档）和 1px 半透明描边 `rgba(255,255,255,.08)` 区分层级。

## 2. 字体排印

### 2.1 字体栈

```css
--font-sans: -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC",
  "Hiragino Sans GB", "Microsoft YaHei", "Helvetica Neue", Arial, sans-serif;
--font-mono: "SFMono-Regular", Consolas, "Liberation Mono", Menlo, monospace;
```

- 中英混排必须包含 PingFang SC / Microsoft YaHei；不要加载超过 2 个外部字体（1 个标题 + 1 个正文已足够）。
- 数字展示（金额/统计）可用 `font-variant-numeric: tabular-nums` 防抖动。

### 2.2 字阶（1.25 Modular Scale）

| Token | 字号 / 行高 | 用途 |
| --- | --- | --- |
| `--text-xs` | 12px / 1.5 | 辅助说明、标签 |
| `--text-sm` | 14px / 1.6 | 次要正文 |
| `--text-base` | 16px / 1.7 | 正文默认 |
| `--text-lg` | 18px / 1.6 | 小标题、强调正文 |
| `--text-xl` | 22px / 1.4 | 卡片/区块标题 |
| `--text-2xl` | 28px / 1.3 | 页面标题 |
| `--text-3xl` | 36px / 1.2 | 大标题、Hero |

规则：

- 中文正文建议 15–16px；`font-weight` 只用 400 / 500 / 600 / 700，中文避免 300 以下（发虚）。
- 中文标题 `letter-spacing: 0.01–0.02em`；纯英文大写标签 `letter-spacing: 0.05–0.1em`。
- 段落最大行宽 `max-width: 65ch`（约 32–38 个中文字），避免一眼扫不完。
- 标题与正文的间距：标题的 `margin-top` 应大于 `margin-bottom`（如 24/8），体现"标题属于下方内容"。

## 3. 间距系统（8px 网格）

间距只允许使用以下档位：`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96`。

```css
--space-1: 4px;  --space-2: 8px;  --space-3: 12px; --space-4: 16px;
--space-6: 24px; --space-8: 32px; --space-12: 48px; --space-16: 64px;
```

常用映射：

- 图标与文字：8px；相关元素组内：8–12px；组间：24px；区块之间：48–64px。
- 卡片内边距：16–24px（小卡 16，标准卡 24）。
- 表单：label 与输入框 8px，字段之间 16–24px。
- 页面容器左右内边距：移动端 16px，桌面 24–32px。

**亲密性原则**：相关的元素靠近（8px），不相关的元素远离（≥24px）。间距层次不明显时优先拉大差距，而不是微调 2px。

## 4. 圆角与阴影

### 4.1 圆角档位

```css
--radius-sm: 6px;   /* 输入框、小按钮、标签 */
--radius-md: 10px;  /* 常规按钮 */
--radius-lg: 14px;  /* 卡片、弹窗 */
--radius-xl: 20px;  /* 大卡片、Hero 区块 */
--radius-full: 9999px; /* 头像、胶囊 */
```

- 同一"视觉层级"用同一档：卡片族统一 `lg`，按钮族统一 `md`。嵌套时内层圆角 = 外层圆角 − 内边距。
- 大圆角（≥14px）偏轻松活泼，小圆角（≤6px）偏专业硬朗——保持与整体风格一致即可，但**全站必须统一**。

### 4.2 阴影（最多 3 层）

```css
--shadow-sm: 0 1px 2px rgba(0,0,0,.05);                    /* 输入框、小元素 */
--shadow-md: 0 4px 12px rgba(0,0,0,.08);                   /* 卡片悬浮、下拉菜单 */
--shadow-lg: 0 12px 32px rgba(0,0,0,.12);                  /* 弹窗、抽屉 */
```

- 阴影必须柔和（大模糊 + 低透明度），禁止 `0 0 Npx rgba(0,0,0,.5)` 式生硬阴影。
- 层级规则：静态卡片可不加阴影只用 1px 边框；hover 时才升为 `md`。同一页面同时可见的阴影层级不超过 2 种。
- 也可用"浅色背景色块 + 无边框无阴影"的扁平层级（Notion 风格），但全站只能选一种层级语言。

## 5. 快速风格对照

| 想要的感觉 | 圆角 | 阴影 | 配色饱和度 | 间距 |
| --- | --- | --- | --- | --- |
| 极简高级（Linear/Notion） | 小 | 无/极淡 | 低饱和 + 大量灰阶 | 大留白 |
| 现代友好（Stripe/Vercel） | 中 | 柔和一层 | 中饱和 + 强调色 | 中等 |
| 活泼年轻（消费/社区） | 大 | 明显、彩色投影 | 高饱和、渐变可用 | 紧凑 |

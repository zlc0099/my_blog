# Frontend Design Simplifier

前端设计简化与去 AI 味
Skill。不是一味做极简，而是减少模板化、装饰性和冗余设计，让页面回归真实产品体验。

## 适用场景

-   新页面开发前：建立设计约束，防止 AI 套用通用模板。
-   开发中：指导布局、视觉和交互实现。
-   页面完成后：诊断 AI 味、冗余、层级和响应式问题。
-   老项目优化：不破坏业务逻辑地精简 UI。

## 核心能力

识别模板化视觉、删除重复信息和无意义容器、调整视觉层级、优化交互和响应式，并按中后台、博客、品牌官网、社区和数据大屏采用不同策略。

## 使用

将 `frontend-design-simplifier` 文件夹放入 Agent/Skill
支持的技能目录，按对应工具的 Skill 加载方式启用。本 Skill 不绑定特定
IDE。

## 推荐提示

-   使用该 Skill 审查当前页面，先给问题清单，不要改代码。
-   按该 Skill 精简管理后台，保持业务功能和接口不变。
-   开发新页面前，先输出页面结构和视觉约束。

# Business Story Simulator v2.0

开发前规划 Skill：帮助用户从"我有个想法"走到"有一份可以交给 AI
编码助手或开发团队执行的计划"。

## 两种用户模式

-   **小白模式**：给不会编码、想借助 AI
    做小项目的人。用大白话、真实场景、示例和易懂选项引导用户；AI
    负责技术分析，用户确认产品行为和体验。
-   **开发者模式**：给懂编码的人。先评估项目复杂度，再采用轻量、标准或深度分析。

注意：小白/开发者是用户模式；轻量/标准/深度是开发者模式下的分析深度，二者不是同一维度。

## 开发者模式分析深度

-   轻量：简单 CRUD、个人博客、单一功能工具。
-   标准：音乐平台、预约系统、内容社区、中型业务应用。
-   深度：ERP、MES、道路巡查、多角色多模块复杂系统。

## 核心流程

小白：想法收集 → 引导提问 → 场景模拟 → 功能取舍 → 页面与操作 → 规则确认
→ 技术建议 → 验收清单 → 开发计划。

开发者：读取资料 → 复杂度评估 → 七层分析 → 反向推演 → 规则追溯 →
三次确认 → 需求基线 → 开发工单。

## 三次确认

1.  方向确认
2.  业务确认
3.  计划确认

## 安装

将 `business-story-simulator` 文件夹放入所使用 Agent/Skill
支持的技能目录，并按对应工具的 Skill 加载方式启用。本 Skill 不绑定特定
IDE 或编码助手。

## 目录

-   `SKILL.md`：主指令
-   `references/`：分析框架、小白引导、确认和追溯规则
-   `templates/`：规划、故事、角色模块和验收模板
-   `examples/`：小白项目与开发者项目示例
